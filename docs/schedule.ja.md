## リスク管理

| リスク | 発生確率 | 影響度 | 対策 |
|---|---|---|---|
| 物理の手触りが悪い | 中 | 高 | Day 3 を Go/No-Go ゲートに設定。インパルスモデルを簡略化して調整 |
| スマホで30fps未満 | 中 | 高 | 剛体数を削減、モバイルはキネマティックのみに切り替え |
| アセット制作が遅れる | 中 | 中 | Box/Sphere などプリミティブをプレースホルダーとして使用 |
| Tier 4/5 が完成しない | 低 | 低 | SHOULD/COULD 扱いのため、Tier 1〜3 で提出可能 |
| PWA Service Worker 不具合 | 低 | 低 | Workbox でエッジケースを吸収、通常Webアプリとして代替提出 |

### Go / No-Go チェックリスト（Day 7 終了時）

```
□ クリックで物理的な反動とともにコグが生産される
□ 機械が毎秒コグを自動生産する
□ 購入パネルのコストと残高計算が正しい
□ セーブ/ロードがブラウザ更新をまたいで機能する
□ デスクトップ Chrome で 55fps 以上を維持
```
