# PHYSICS FACTORY — アセット計画

## 1. 概要

すべてのアセットは `architecture.ja.md` で定義した予算内に収める必要があります。

| カテゴリ | 予算 | フォーマット |
|---|---|---|
| 3Dモデル | ≤ 8 MB（Draco 圧縮） | `.glb` |
| テクスチャ | GLB 内に KTX2 で同梱 | — |
| SFX | ≤ 1.5 MB | `.ogg` / `.mp3` |
| BGM ステム | ≤ 2 MB | `.ogg` / `.mp3` |
| HDR 環境マップ | ≤ 512 KB | `.env`（Babylon 圧縮形式） |
| PWA アイコン | ≤ 50 KB | `.png` 192×192、512×512 |

## 2. 3Dモデル

### 2.1 機械（ティア別）

| アセット | ポリゴン目標 | 制作方法 | 工数目安 |
|---|---|---|---|
| ハンドクランク（Tier 1） | ≤ 500 tris | Blender — グリップ + ギアのモジュール制作 | 2h |
| 蒸気ピストン（Tier 2） | ≤ 800 tris | Blender — シリンダー + ロッド + ベース | 3h |
| ギアアレイ（Tier 3） | ≤ 1,200 tris | Blender — プロシージャルギアアドオン | 3h |
| ボイラーエンジン（Tier 4）*(SHOULD)* | ≤ 1,500 tris | Blender — タンク + パイプ + バルブ | 4h |
| エーテルコンデンサー（Tier 5）*(COULD)* | ≤ 1,000 tris | Blender — クリスタル + フレーム | 3h |

### 2.2 環境

| アセット | ポリゴン目標 | 制作方法 | 工数目安 |
|---|---|---|---|
| 工場フロアタイル（モジュラー×4バリアント） | ≤ 各400 tris | Blender — レンガ + 金属プレート | 3h |
| 壁パネル（モジュラー×2バリアント） | ≤ 各300 tris | Blender — リベット打ちアイアンプレート | 2h |
| コンベアベルトセクション | ≤ 600 tris | Blender — ベルト + ローラー | 2h |
| パイプクラスター（装飾） | ≤ 400 tris | Blender — チューブ + フランジ | 1h |

**環境アセット合計**: ≈ 8h

---

## 3. テクスチャ（PBR）

すべてのテクスチャは **KTX2 + Basis Universal** 圧縮で GLB 内に同梱します。

| マップ | 解像度 | 備考 |
|---|---|---|
| ベースカラー | 512×512 | スチームパンクパレット: 真鍮・銅・鋳鉄 |
| メタリック-ラフネス | 512×512 | 金属部: metallic=0.9、roughness=0.3 |
| ノーマル | 512×512 | ジオメトリコストを抑えた表面ディテール |
| エミッシブ *(任意)* | 256×256 | インジケーターライト・発光シーム |

制作方法: **Substance Painter**（試用版）または **AI生成PBR**（Adobe Firefly / Materialize）+ 手動修正。
工数目安: ≈ 3h

---

## 4. HDR 環境マップ

- スタイル: スチームパンク鋳造所内部 — 暖色オレンジのポイントライト + 冷色ブルーのアンビエント
- 素材源: [Poly Haven](https://polyhaven.com/)（CC0）または Blender でカスタムHDRI をレンダリング
- Babylon Sandbox または `@babylonjs/tools` で Babylon `.env` 形式に変換
- 工数目安: 1h

---

## 5. オーディオ

### 5.1 SFX マトリクス

| トリガーイベント | SFX の内容 | 素材源 |
|---|---|---|
| 機械をクリック | 金属のカチン音（ピッチをランダムに±5%変化） | フリーSFX（CC0）— Freesound.org |
| 自動ティック | 柔らかい機械的なチック音 | フリーSFX（CC0） |
| 機械を購入 | 重厚なクランク音 + レジスター音 | フリーSFX（CC0） |
| プレステージ | 蒸気汽笛ファンファーレ | フリーSFX（CC0）/ Audacity で合成 |
| マイルストーン解放 | 上昇するチャイム音 | フリーSFX（CC0） |
| ギア回転（Tier 3以降） | 低音のうなりループ | フリーSFX（CC0）、ループ設定 |
| 蒸気噴射（Tier 4） | シューという音のループ | フリーSFX（CC0）、ループ設定 |

### 5.2 BGM レイヤー

| レイヤー | 内容 | 有効条件 |
|---|---|---|
| Layer 0 | 工場アンビエントドローン（ベース） | 常時 |
| Layer 1 | 柔らかいジャズピアノ + ブラシドラム | 機械を1台以上購入 |
| Layer 2 | ストリングス追加 | 合計5台以上 |
| Layer 3 | ブラス + フルパーカッション | 合計15台以上 |
| Layer 4 | プレステージファンファーレ | プレステージ発動時 |

素材源: **AI生成**（Suno / Udio）またはロイヤリティフリーのスチームパンクジャズ（CC0）。
工数目安: 2h
