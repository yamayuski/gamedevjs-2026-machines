# PHYSICS FACTORY — ゲーム仕様書

## 1. 機能要件

### 🔴 MUST（提出に必須）

| ID | 要件 | 詳細 |
|---|---|---|
| M-01 | クリック生産アクション | 画面上のクランク/ピストンをクリックすると Havok インパルスが発生し、リソースを獲得 |
| M-02 | 最低3段階の機械ティア | Tier 1: ハンドクランク → Tier 2: 蒸気ピストン → Tier 3: ギアアレイ |
| M-03 | 自動生産 | 購入した機械が固定レート（秒間）でリソースを生産し続ける |
| M-04 | リソース表示 | アニメーション付きカウンターでリソース合計をリアルタイム表示 |
| M-05 | 購入/アップグレードパネル | コストと生産レートを並べたサイドバーUI |
| M-06 | マイルストーン通知 | 主要アンロック時にポップアップまたはバナーを表示 |
| M-07 | タイトル画面 | ゲームタイトル・スタートボタン・クレジット |
| M-08 | PWA対応 | `manifest.json` + Service Worker によるオフラインプレイとホーム追加 |
| M-09 | PC＋モバイル対応 | タッチ対応UI・ビューポートに合わせたキャンバスリサイズ |

## 2. 非機能要件

| カテゴリ | 要件 | 目標値 |
|---|---|---|
| パフォーマンス | フレームレート | 60fps（デスクトップ）/ 30fps（スマホ中級機） |
| 物理剛体数 | 同時アクティブ剛体 | ≤ 50個（装飾+クリック可能） |
| ロード時間 | 初回バンドル | ≤ 10MB（GLTF圧縮 + PBRテクスチャ） |
| ブラウザ互換 | 対応ブラウザ | Chrome/Edge/Firefox 最新版、Safari iOS 16.4+ |
| オフライン | PWAインストール | 初回ロード後はネットワークなしで完全プレイ可能 |

## 3. ゲームメカニクス詳細

### 3.1 リソース

- **コグ（Cogs）** — 全機械が生産するメイン通貨。
- **スチームプレッシャー** — Tier 2 解放後に登場するサブリソース。Tier 3 機械の購入に必要。

### 3.2 機械ティア

| ティア | 名称 | コスト | コグ/秒 | 物理演出 |
|---|---|---|---|---|
| 1 | ハンドクランク | 10 | 0.5 | クリック時にクランクメッシュが回転（Havok Hinge インパルス） |
| 2 | 蒸気ピストン | 120 | 4 | ピストンが上下移動（PhysicsBody キネマティック） |
| 3 | ギアアレイ | 1,500 | 25 | 複数ギアが連動回転（ConstraintMotor 角速度） |
| 4 *(SHOULD)* | ボイラーエンジン | 20,000 | 150 | 蒸気パーティクル噴出（剛体エミッター） |
| 5 *(COULD)* | エーテルコンデンサー | 300,000 | 1,000 | 光るクリスタル＋フォースフィールド（シェーダー+物理） |

### 3.3 プレステージループ *(SHOULD)*

1. 累計生産コグ ≥ 1,000,000 でプレステージ解放。
2. 全機械とコグをリセット、500,000コグにつき **ブループリント** 1枚を獲得。
3. ブループリント1枚につき全体生産量 +10% の永続乗数を付与。

### 3.4 クリックフィードバックパイプライン

```
機械メッシュをポインターダウン
      │
      ▼
Havok applyImpulse（ビジュアル的な反動）
      │
      ▼
リソースデルタを累計に加算
      │
      ▼
SFXクリップを再生（ピッチをランダムに±5%変化）
      │
      ▼
クリックパーティクルバーストを放出
      │
      ▼
リソースカウンターをアニメーション（+デルタが上に浮き上がる）
```

## 4. 入力設計

### デスクトップ

| 入力 | アクション |
|---|---|
| 機械を左クリック | リソース生産 |
| 購入ボタンを左クリック | 機械を購入 |
| キャンバスをドラッグ | 工場周囲のカメラ回転 |
| スクロールホイール | カメラズーム |
| `R` | カメラをデフォルトにリセット |

### モバイル

| 入力 | アクション |
|---|---|
| 機械をタップ | リソース生産 |
| 購入ボタンをタップ | 機械を購入 |
| 1本指ドラッグ（キャンバス） | カメラ回転 |
| ピンチ | カメラズーム |
| HUDボタン | 購入 / プレステージ |
