# PHYSICS FACTORY — プロジェクト概要

## コンセプト

**PHYSICS FACTORY** は [Babylon.js](https://www.babylonjs.com/) と [Havok](https://www.havok.com/) 物理エンジンで作るブラウザ向け3Dクリッカー/アイドルファクトリーゲームです。

プレイヤーはクランクを回したりピストンを押したりといった物理的なアクションを起こしてリソースを生産し、工場を少しずつ自動化していきます。インストール不要のブラウザゲームで、PWAによるオフラインプレイにも対応します。

## テーマ: MACHINES（機械）

ゲームのあらゆる要素が「機械」です。

- 生産ユニットはギア・ピストン・ボイラー・コンベアベルト。
- アップグレードは機械的な改造（大型フライホイール、軸受けの潤滑など）。
- 工場フロアはリアルタイム物理シミュレーションで動き続ける生きた空間。

## コアループ

```
クリック → リソース生産
リソース → 機械を購入
機械 → クリックを自動化
自動化 → 新しい機械ティアを解放
新ティア → より迫力のある物理スペクタクル
```

## 審査5軸への対応（GameDevJS Jam）

| 審査軸 | アプローチ | 達成目標 |
|---|---|---|
| **Innovation** | アイドル/クリッカーへのリアルタイム Havok 物理導入 | クリックと自動化ティックのたびに物理反応が見える |
| **Theme** | ゲームメカニクス全てが文字通り「機械」 | 工場設定・機械的アップグレード・ギア駆動のビジュアル |
| **Gameplay** | 明確なマイルストーンを持つ満足感のあるフィードバックループ | 30秒以内に最初のアップグレード、3分以内に工場が自走 |
| **Graphics** | Babylon.js PBR + IBL、ブルームポストプロセス | スチームパンクな金属質感、全ティアで一貫したクオリティ |
| **Audio** | 物理イベント駆動SFX（クリック音、チック音、衝突音） | すべてのアクションに聞き応えのある固有の音 |
